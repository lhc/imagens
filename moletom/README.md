## Repositório de Imagens — Moletom LHC

Este repositório contém os arquivos de imagens utilizados no desenvolvimento e os modelos finais dos moletons do projeto.

Todo o histórico de discussões, decisões e orçamentos relacionados a este material pode ser acompanhado no Discourse, através do link abaixo:
https://discourse.lhc.net.br/t/or%C3%A7amento-e-fornecedores-moletom-lhc/1345

### 📁 Estrutura do repositório

```
.
├── modelos/                        # Modelos finais de moletom
│   ├── canguru_cinza.jpeg
│   ├── canguru_preto.jpeg
│   ├── moletom_curiosity_v1.pdf
│   ├── moletom_cinza_final.jpeg
│   └── moletom_preto_final.jpeg
│
├── raw_img/                        # Imagens base utilizadas nas estampas
│   ├── capivara_no_background.svg
│   ├── capivara.svg
│   └── forro_touca.jpg
│
└── README.md

```
#### Descrição das pastas

- modelos/
Contém os arquivos finais dos moletons, já com definição de cores, estampas e layout.

- raw_img/
Armazena as imagens base utilizadas no processo de criação das estampas (arquivos originais, vetores e referências).
